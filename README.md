# Expiry Control - Backend

Backend project for Expiry Control, an application focused on managing products with expiration dates.

The main objective of the system is to help users and small businesses manage products that are close to expiring or already expired through alerts and statistics.

---

# Technologies Used

- Java
- Spring Boot
- Maven
- PostgreSQL
- IntelliJ IDEA

---

# Dependencies Used

- Spring Web
- PostgreSQL Driver
- Lombok

---

# Current Features

The backend currently includes REST endpoints created to simulate application functionalities.

Available endpoints:

- /hello
- /register
- /login
- /estado
- /vencidos
- /estadisticas
